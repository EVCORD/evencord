Getting started

Which platforms are supported?

The initial beta targets Windows x64 and Discord Stable 1.0.9266 with the exact approved archive hash. PTB, Canary, ARM64, Linux, macOS, browsers and standalone applications are not supported by this installer.

Can I keep another Discord modification?

Settings can coexist in separate folders, but two mods cannot own the same Discord loader. Remove the other modification using its supported method before installing. Private EvenCord previews use a different trust configuration and are not automatically converted by the public beta installer.

Will my old settings be imported?

No. EvenCord uses its own %APPDATA%\EvenCord settings root. Settings are never imported automatically. To transfer compatible plugin preferences, export a JSON backup from Vencord or Equicord, back up your EvenCord settings, then use Backup & Restore > Import Plugins and restart. This imports preferences for included plugins, not custom plugin code or local theme files. Uninstalling preserves EvenCord settings.

What if installation or a Discord update fails?

Keep the original archive and recovery records. Close Discord yourself, then use Recover for interrupted operations or Repair for a supported installation. New Discord archives require reviewed compatibility metadata. Do not delete app.asar or _app.asar by guesswork.

Are automatic updates enabled?

From beta.3, managed installations automatically check the signed EvenCord beta channel and notify you. New installations download updates automatically; existing preferences are preserved. You can change background downloads in EvenCord > Updater. Update alerts use the inherited notification popup. Click an available-update popup to open the updater; a ready popup offers restart only after verified staging. Download progress and the verified running version are shown there. Restart is offered only after signature, size, hash, compatibility and staging checks pass. Older betas need the one-time installer upgrade. Unavailable or incompatible releases show an explanation instead of forcing installation. Installer self-update and host repatching remain disabled.

Do upstream plugin changes arrive immediately?

Equicord changes are detected by a read-only upstream review every 12 hours. They must then be reviewed and incorporated into an authenticated EvenCord release. Plugins ship together with the core, including Reclip. Pushing plugin source to GitHub alone does not publish an update.

Is this an official Discord product?

No. EvenCord is independent and is not affiliated with Discord Inc., Vencord or Equicord. Client modifications may conflict with Discord’s terms. There is no guarantee against account restrictions. Review Discord’s terms before use.

Reclip: recording and privacy

Reclip captures the main Discord window’s video into a rolling memory buffer. The default duration is two minutes, subject to the memory limit. Saving writes recent footage to your selected folder. Choose folder in Reclip settings opens the native folder picker. The default is Windows Videos\Reclip. Older recordings in Videos\bossclip stay there, and custom folder choices are preserved. Unsaved footage is discarded when recording stops or Discord closes.

Audio is not restricted to Discord. Windows loopback can include other applications on the default output device. The microphone records independently of Discord mute and push-to-talk. Choose Microphone off to exclude it. Get participants’ consent where required before recording.

Recording starts manually unless you enable Auto Start. Clips remain local; Reclip does not automatically upload them or delete older clips. WebM works without FFmpeg; MP4 and MKV conversion require your own FFmpeg installation. Capture can freeze when minimized, locked or suspended. Discord must use the Windows default output for loopback.

Quoter Enhanced: media limits

Quoter Enhanced preserves the customized quote layout, Arabic typography and image, sticker and animated-media support. GIF providers, expired links, media size limits and network restrictions can prevent animation retrieval or export. Support is experimental; no claim of universal GIF compatibility is made.

Its source badge identifies the maintained distribution, not exclusive authorship. Original Quoter authors and the Valenced reference remain credited.
