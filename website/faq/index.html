Getting started

Which version should I download?

Choose Windows, macOS or Linux on the download page, then select your device. The macOS Universal download works with both Apple silicon and Intel.

How do I install EvenCord?

Close Discord, open EvenCord, select your Discord installation and choose Install. Reopen Discord when finished.

What if EvenCord is missing?

Download the latest EvenCord, close Discord and choose Repair. Your settings, themes and plugin preferences are kept.

Can I switch from another mod?

Remove the other client modification with its own installer before installing EvenCord. Compatible plugin preferences can be transferred through Backup & Restore.

How do updates work?

Open EvenCord > Updater to check for updates or change automatic download preferences. Restart Discord when an update is ready.

Is EvenCord an official Discord app?

No. EvenCord is an independent project based on Equicord and Vencord. Client modifications may conflict with Discord's terms.

Reclip: recording and privacy

Reclip captures the main Discord window’s video into a rolling memory buffer. The default duration is two minutes, subject to the memory limit. Saving writes recent footage to your selected folder. Choose folder in Reclip settings opens the native folder picker. The default is Windows Videos\Reclip. Older recordings in Videos\bossclip stay there, and custom folder choices are preserved. Unsaved footage is discarded when recording stops or Discord closes.

Audio is not restricted to Discord. Windows loopback can include other applications on the default output device. The microphone records independently of Discord mute and push-to-talk. Choose Microphone off to exclude it. Get participants’ consent where required before recording.

Recording starts manually unless you enable Auto Start. Clips remain local; Reclip does not automatically upload them or delete older clips. New WebM and MKV clips include seek indexes and need no external converter. MP4 needs FFmpeg with H.264/AAC support. Reclip can detect standard Windows and WinGet installations, or you can choose ffmpeg.exe in its settings. Conversion failures preserve WebM and identify the actual saved format. Capture can freeze when minimized, locked or suspended. Discord must use the Windows default output for loopback.

Quoter Enhanced: media limits

Quoter Enhanced preserves the customized quote layout, Arabic typography and image, sticker and animated-media support. GIF providers, expired links, media size limits and network restrictions can prevent animation retrieval or export. Support is experimental; no claim of universal GIF compatibility is made.

Its source badge identifies the maintained distribution, not exclusive authorship. Original Quoter authors and the Valenced reference remain credited.
