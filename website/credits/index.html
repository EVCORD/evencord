EvenCord is an open-source Discord client modification based on Equicord, which inherits Vencord. Original plugin names, authors, licensing and Git ancestry remain intact.

Upstream projects

  • Equicord: the sole regular upstream for the core.
  • Vencord: the original client modification foundation.
  • Esharq: compatible custom plugins, with original authors, logo and GPL license preserved. Integration details.
  • Equilotl: the installer foundation, derived from the Vencord installer.
  • Valenced Quoter: the Android layout and media reference, credited to Benjii in its manifest.

Contributors and licenses

The core retains GPL-3.0-or-later notices; the installer retains its GPL license and original notices. Corresponding source is linked from each release. See each repository’s LICENSE, source headers and dependency notices for applicable terms.
