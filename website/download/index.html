Install in three steps

  1. Start with Discord Stable.

    Install the official Windows x64 app. Fully quit Discord, including its tray process, before making changes.

  2. Use the EvenCord Installer.

    Choose Detect Discord Stable, then Install / Update. The installer retrieves signed metadata and verifies the payload before replacing the loader. If your archive is unsupported, stop and report its version. Do not bypass the check.

  3. Open Discord and make it yours.

    Find EvenCord in settings. Enable the plugins you want, and review recording permissions before starting Reclip.

Before you download

The executable is not Windows Authenticode signed. Windows may display an unknown-publisher or SmartScreen warning. Ed25519 release signatures authenticate release metadata; they are a different mechanism and do not create Windows publisher trust. If uncertain, do not run the file. Do not disable Windows security globally.

Another client modification must be removed with its own supported uninstaller first. EvenCord refuses foreign or unrecognized loaders; it does not replace them for you.

Updates, repair and removal

Automatic updates, installer self-update and automatic Discord repatching are disabled for this beta. Use a newly downloaded, verified installer for manual upgrades. A Discord update may remove the modification or require a newly approved archive.

Repair re-verifies the available release. Uninstall restores the original Discord archive while retaining EvenCord settings. Recover handles an interrupted transaction. Keep recovery files intact and report errors instead of deleting loaders manually.
