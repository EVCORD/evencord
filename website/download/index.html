Install in three steps

  1. Save your work and close Discord.

    Choose the installer for your operating system and architecture from the release assets.

  2. Install or repair EvenCord.

    Select your Discord installation. Existing EvenCord settings and themes are retained. Remove another client modification with its own installer before switching.

  3. Open Discord.

    Find EvenCord in settings and enable the plugins you want.

Updates

EvenCord checks its own GitHub releases after startup and every 15 minutes. Automatic downloads follow your preferences. Downloads are checked against the release asset size and GitHub SHA-256 digest before restart is offered. Equicord source changes are checked every six hours, integrated with EvenCord additions, tested and published. Source conflicts stop publication for review.

Existing installations

Version 1.1.0 transitions managed Windows installations through their existing signed updater to the normal Equicord based loader. If EvenCord is missing, use the latest installer and choose Repair. Your settings remain in the EvenCord profile. Uninstall restores Discord's original archive.

Platform builds

Windows, macOS and Linux use the inherited Equilotl installation paths. Release assets list the builds currently available. Build checks and fixture tests do not guarantee every Discord version or plugin works on every device. Windows installers are not Authenticode signed, and macOS builds use ad hoc signing.
