Install in three steps

  1. Choose your Discord channel.

    Install the official Windows x64 Stable, PTB or Canary app. Save unsaved clips or work before continuing. The installer closes the selected Discord installation before making changes; other channels stay open.

  2. Use the EvenCord Installer.

    Select Stable, PTB or Canary in the installer, then choose Install EvenCord. Settings, themes, plugin preferences and recovery are isolated for each channel. The installer retrieves signed metadata and verifies the payload before replacing the loader. If your archive is unsupported, stop and report its version. Do not bypass the check.

  3. Open Discord and make it yours.

    Find EvenCord in settings. Enable the plugins you want, and review recording permissions before starting Reclip.

Before you download

The executable is not Windows Authenticode signed. Windows may display an unknown-publisher or SmartScreen warning. Ed25519 release signatures authenticate release metadata; they are a different mechanism and do not create Windows publisher trust. If uncertain, do not run the file. Do not disable Windows security globally.

Another client modification must be removed with its own supported uninstaller first. EvenCord refuses foreign or unrecognized loaders; it does not replace them for you.

Updates, repair and removal

Already seeing default Discord after a Canary update? Download installer beta.7, select Canary and use Install or Repair. Your existing EvenCord profile is retained. Older clients cannot retrofit the host-update hook before their first restart, so this one-time repair is required on affected installations.

Beta.1 and beta.2 need a one-time manual upgrade: fully close Discord, open the beta.3 installer and choose Update EvenCord. From beta.3, managed installations check signed EvenCord releases after startup and every 15 minutes. Automatic downloads follow your setting in EvenCord > Updater. A verified, compatible update is staged with recovery data; restart only when the updater says it is ready. Installer self-update remains disabled. From core beta.8, compatible Discord host updates are repatched through verified ownership and signed archive checks. The EvenCord restart action blocks an unsafe host handoff. A new Discord archive requires a compatibility review.

Repair re-verifies the available release. Uninstall restores the original Discord archive while retaining EvenCord settings. Recover handles an interrupted transaction. Keep recovery files intact and report errors instead of deleting loaders manually.
