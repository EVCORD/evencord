# Community additions

EvenCord includes adapted community plugins. Inclusion does not imply exclusive authorship.

| Plugin | Original source and credit |
| --- | --- |
| PullUser | [viciouscal/Vencord](https://github.com/viciouscal/Vencord/tree/68a2cf7d4f18dc4b7ffbea51ad82b7c005784af3/src/plugins/pulluser), viciouscal. Adapted to event-driven voice updates and permission checks. |
| FakeDeafen | [viciouscal/Vencord](https://github.com/viciouscal/Vencord/tree/68a2cf7d4f18dc4b7ffbea51ad82b7c005784af3/src/plugins/fakeDeafen), desu and viciouscal. Adapted to EvenCord's UserAreaAPI without the external PhilsPluginLibrary dependency. |

VoiceChatUtilities (in voiceChatUtils), HomeTyping, UnlimitedAccounts and WhosWatching already exist in the Equicord base. They remain upstream plugins, with their existing authors, source identity and update path. They are not duplicated or reclassified as EvenCord additions.

The supplied VoiceChatUtilities JSON link is a translation file; its implementation is the vcvoiceChatUtilities directory linked above. GPL-3.0-or-later and existing source notices are preserved.
