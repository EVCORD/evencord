# EvenCord 1.0.0

The first stable-channel EvenCord release for Windows x64, supporting reviewed Discord Stable, PTB and Canary installations.

- Removed obsolete development and phase notices from settings and About.
- Stable releases use the existing signed updater, with automatic checks, notifications, verified staging and user-controlled restart.
- Existing update-enabled beta installations receive a signed transition update first, followed by this release. Settings, themes, plugin preferences and recovery remain in place.
- Reclip and Quoter Enhanced remain available alongside inherited Equicord and Vencord plugins, with their distinct source badges and original authorship.
- Installation retains process-permission handling, loader ownership checks and recovery safeguards.

Equicord is the sole regular core upstream. Its changes are reviewed and incorporated into signed EvenCord releases; upstream commits are not installed directly.

Supported archive compatibility remains explicitly verified. Future Discord archives may require an updated compatibility catalog. Reclip MP4 requires FFmpeg; Quoter Enhanced external GIF support remains subject to provider and media restrictions. The stable channel designation does not promise error-free operation. Report reproducible issues through the repositories.

Artifacts use pinned Ed25519 release-metadata signatures with SHA-256 and size checks. Windows executables are not Authenticode signed. Installer self-update and cloud synchronization remain unavailable. Old private previews and builds with updates disabled require a manual installer upgrade.
