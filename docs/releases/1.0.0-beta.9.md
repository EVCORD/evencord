# EvenCord stable-channel transition

This final transition update lets existing managed beta installations receive EvenCord 1.0.0 and future stable releases automatically through the signed updater. Install this update and restart Discord; the stable release will then be offered through the same updater. Automatic downloads continue to respect your preference.

The updater promotes only a newer authenticated stable release with a higher release sequence. It preserves the original Discord archive, last working payload, settings, themes and plugin preferences. The loader's trusted signing key is unchanged. Its channel policy is migrated with resumable ownership records. Unrecognized or changed loaders are rejected.

Removed outdated development-phase notices from settings and About. EvenCord continues to inherit plugins and improvements from Equicord, which includes Vencord changes. Upstream changes reach users after review and publication as an EvenCord release.

Windows x64 Stable, PTB and reviewed Canary archives remain supported. This transition does not modify Discord while the source is being developed. Very old installations with updating disabled or a different private-preview key still require the current installer.
