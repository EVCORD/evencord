# EvenCord 1.0.1

Adds five plugins to the official EvenCord source category. All are disabled by default; original authors and GPL notices are preserved.

- **BetterMicrophone** adds desktop microphone profiles and transport controls. **PhilsPluginLibrary** supplies the shared profile and voice-panel UI and is enabled as its dependency.
- **FollowUser** adds a context-menu action and toolbar indicator for following a chosen user's accessible voice channel. It respects Discord channel permissions and limits.
- **PasscodeLock** adds an optional local passcode screen, keyboard shortcut and auto-lock timer. This is a casual-access screen lock, not account encryption or operating-system security.
- **DontControlMe** adds voice-channel pinning and reconnection. Optional server mute/deafen requests require your existing Discord permissions; they cannot bypass moderation.

Adapted notification and modal APIs, removed an unrelated missing FakeDeafen dependency, preserved author names, and corrected listener/transport cleanup. Settings-export JSON files were excluded.

BetterMicrophone native stereo support is experimental, Windows x64 only and separately opt-in. Its third-party addon and configuration are pinned to a fixed release with size/SHA-256 checks. No native code is downloaded while that option is disabled. Microphone-related patches exclude unrelated video patches. Discord voice-module changes can make patches unsupported; native compatibility and plugin UI/voice behavior remain for manual testing.

Existing stable users receive this core through the signed updater. The current 1.0.0 installer retrieves the latest compatible stable payload; reinstalling is not required for update-enabled installations. Existing settings, themes and plugins are preserved. Source uploads alone do not trigger a client update; see [the plugin publishing process](https://github.com/alrimii/evencord/blob/main/docs/PLUGIN-RELEASES.md).
