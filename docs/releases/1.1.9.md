# EvenCord 1.1.9

Redesigned the message-deletion interface with an Arabic right-to-left layout, a dedicated conversation sidebar and a clearer message-review area.

Conversation types now use a compact selector, optional filters stay tucked away, and each message has a clear timestamp and original-message link. Search progress, pause controls and final confirmation appear where they are needed. The interface adapts to smaller windows.

Simplified the Arabic wording throughout the interface and plugin settings.
