# EvenCord 0.1.0-beta.4

Reclip now saves new clips in Videos/Reclip by default. The settings label, default-folder button and recording documentation use the plugin's current name.

Custom folder choices are preserved. Existing clips in Videos/bossclip are not moved or deleted. Use Open clips for the new default folder; older recordings remain accessible through File Explorer. Other recording settings are unchanged.

Managed beta.3 installations can receive this signed core update through EvenCord > Updater. Automatic checks run after startup and every 30 minutes. Automatic downloads follow your existing preference. After verified staging, choose Update ready and restart Discord.

The existing beta.3 installer also retrieves this release for fresh installations and manual upgrades; a new installer executable is unnecessary for this plugin-only change. Windows x64 and the approved Discord Stable archive are still required. Settings, themes and plugin preferences are preserved.
