# EvenCord 0.1.0-beta.5

- Update alerts now use the inherited Vencord notification popup instead of the Discord top notice banner. Click an available-update notification to open the updater. Click the ready notification to restart only after the staged payload is revalidated. Existing notification position and Windows-notification preferences are respected.
- Updater controls wrap on narrow windows. Download progress, signatures, compatibility checks and recovery remain unchanged.
- Import Plugins now merges plugin preferences only and preserves general EvenCord settings. Compatible JSON backups can restore settings for plugins included in EvenCord; they cannot install custom plugin source. Export a backup before importing and restart afterward.
- A read-only scheduled Equicord upstream review reports new commits, plugin changes and merge conflicts. It cannot merge, sign or publish releases. Vencord changes are inherited through Equicord and reach users after review and a signed EvenCord release.

This is a testing beta for Windows x64 and the approved Discord Stable archive, not a guarantee of compatibility with every Discord version or plugin. Existing foreign modifications must be removed with their supported installer before installing EvenCord. Installer beta.3 can install this core release. Automatic Discord host repatching remains disabled. No installed Discord files are changed during development.
