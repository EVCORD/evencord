# EvenCord 1.1.7

Clear Arabic descriptions and setup guides for Reclip, EvenClean and Quoter Enhanced inside EvenCord settings.

Reclip now explains starting the replay buffer, saving recent moments, shortcuts, Windows capture, system and microphone audio, quality, local storage and export formats. EvenClean explains previewing and confirming your own messages before deletion. Quoter Enhanced explains quote previews, Arabic fonts and media options.

The official Discord plugin forum now highlights these three EvenCord additions with updated Arabic guides and integrated buttons.
