# EvenCord 0.1.0-beta.3

- Reclip now has a native save-folder picker. Its default remains Videos/bossclip. Existing recordings and all recording preferences are preserved.
- Managed Windows x64 installations check the signed EvenCord beta channel after startup and every 30 minutes. Enable automatic downloads in EvenCord > Updater to stage compatible updates in the background, or download when notified.
- The updater verifies the installed signed identity, pinned Ed25519 key, source commit, loader ownership, signed release identity, artifact size, SHA-256 and approved Discord archive before changing the selected payload.
- Download progress and authenticated release notes are shown in the updater. "Update ready — Restart Discord" appears only after verified staging. Discord does not restart automatically.
- Settings, plugins, themes and recordings are preserved. Failed startup can fall back to the previous verified payload. This cannot detect every plugin, voice or UI regression.

## One-time upgrade

Beta.1 and beta.2 had in-client updates disabled. Download the beta.3 installer, fully close Discord yourself, and choose Update EvenCord for your existing supported installation. Reopen Discord. The updater shows the signed running version and trusted key. Keep your existing update preference; automatic downloads are optional. No Equicord settings are imported.

Windows x64 and Discord Stable with the reviewed 1.0.9266 archive remain required. Unsupported archives are rejected without forcing installation. Installer self-update, automatic host repatching and cloud sync remain disabled. Upstream Equicord changes must be reviewed and published as an EvenCord release before users receive them.

Executables are not Windows Authenticode signed. Ed25519 authenticates release metadata and artifacts, not the Windows publisher. Preserve recovery files. Functional testing of the native folder dialog and in-client UI remains with beta testers; focused protocol/recovery tests and compilation are the release checks.
