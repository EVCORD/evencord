# EvenCord 0.1.0-beta.8

## Recovery for users who returned to default Discord

Download installer beta.7, select the affected channel and choose Install or Repair. Your EvenCord settings remain in their existing channel profile. Do not delete your settings or original Discord archives. Canary 1.0.1286 is now independently verified and approved. Older builds had Discord-host repatching disabled and cannot retrofit this handoff before their first restart; affected Canary users need this one-time installer repair.

## Discord update persistence

The existing upstream Discord-update hooks are restored, using EvenCord's ownership checks, signed archive eligibility and separate channel profiles. Only compatible fresh sibling versions in the same Discord installation and channel may be patched. Foreign modifications, unapproved archives and changed recovery data are rejected. Interrupted host patching restores the verified original where safe and retains recovery records if cleanup cannot finish.

The EvenCord update restart action revalidates the staged payload and prepares the pending Discord version before invoking restart. If the pending version cannot be prepared, restart is blocked with an explanation and the current session stays open. This protects the in-client update action; a user can still close Discord manually, and unknown future host archives require a reviewed release or installer repair.

Reclip export and notification improvements from beta.7 are preserved. Windows x64 Stable, PTB and approved Canary versions remain supported. This is a beta; real Discord UI and host-updater runtime testing remains with testers.
