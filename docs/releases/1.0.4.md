# EvenCord 1.0.4

Fixes oversized settings artwork from BetterMicrophone and its shared icon library. The imported microphone, camera and screen-share settings SVGs had 1000-by-1000-pixel default dimensions. They now default to 20 pixels while preserving their original vector viewBox and caller sizing.

The microphone voice-panel button also passes an explicit 20-pixel size and bounded inline dimensions, so it cannot inherit the old oversized default. Plugin activation choices, microphone profiles, native-patching preferences and other user settings are unchanged.

The signed stable updater delivers this fix. Validation was limited to rendering the icon component output with a lightweight JSX stub, changed-file lint, the build and signed-package verification. No browser or Discord runtime testing was performed. This fixes the identified oversized icon source; any other reported issues still require specific reproduction details.
