# EvenCord 0.1.0-beta.7

- Reclip exports now include a finite segment size, duration, seek head and keyframe cue index. New WebM and MKV clips support seeking without first remuxing them through FFmpeg. Existing clips are not rewritten.
- MKV saves directly as Matroska with the original video/audio streams and no external converter. MP4 still uses FFmpeg for H.264/AAC conversion.
- MP4 conversion finds FFmpeg in PATH, standard Windows locations and WinGet packages, including tools installed after Discord was launched. Choose ffmpeg.exe in Reclip settings if automatic discovery cannot find it. The selected executable path is stored natively per channel and is not imported from plugin-setting backups. Conversion failures preserve the WebM and report the reason.
- Automatic release checks run five seconds after startup and every 15 minutes, with throttled focus/reconnection checks and retry backoff after failures. Update alerts are kept until Discord is focused and shown inside Discord instead of relying on Windows notification delivery. Background-download and completion-notification preferences are preserved. Restart is offered only for a verified staged update.

Install this core update once through EvenCord > Updater if your older build is missing automatic alerts. The current installer beta.6 also retrieves it. Stable, PTB and Canary profiles and their settings are preserved. Functional recording and Discord UI testing remains with beta testers; focused synthetic export/seek/conversion and scheduling checks passed.
