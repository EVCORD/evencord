# EvenCord 1.1.0

Integrates the current Equicord source and restores its normal desktop loader and host update hooks. EvenCord branding, profiles and plugins remain available. Imported plugin interfaces have been adapted to the updated Equicord APIs.

Existing managed Windows installations transition through this signed release to the normal EvenCord payload. New releases follow the Equicord build and update model, with downloads verified against GitHub's SHA-256 asset digest. New installations use the Equilotl based cross-platform installer; legacy signing metadata is retained for this transition.

Equicord changes are checked every six hours. Source conflicts or failed validation block publishing. Maintainer UI and plugin changes ship from main after validation and a version increase. The installer now uses the inherited Windows, macOS and Linux installation paths. Platform build checks do not replace testing on actual devices.
