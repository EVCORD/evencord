# EvenCord 1.0.3

Adds **EvenClean**, an opt-in message-cleanup plugin with a fixed-batch preview and explicit deletion confirmation.

- Select accessible server channels, DMs or groups. Filter your own messages by text, dates, attachments and links; pinned messages are excluded by default.
- Preview up to 5,000 matching messages, reveal text only when wanted, and optionally export the preview locally. Deletion requires acknowledging the risk notice and typing the exact batch count.
- One request at a time, Discord REST-client integration, server-provided retry/reset waits, adaptive backoff and bounded retries. Authentication and permission failures stop the job. No account token extraction or storage.
- Pause/resume/stop, progress and cooldown display. No unattended scheduling or automatic startup jobs. Disabling the plugin, logging out or switching accounts cancels new work and clears the preview.

Enable EvenClean in the plugin manager, then use Open EvenClean in its settings or the trash button in the channel toolbar. Existing settings remain intact. Installations that skipped 1.0.2 also receive its one-time opt-in reset for the five previously imported plugins, retaining their configuration. The existing signed stable updater and installer deliver this core release.

Deletion is permanent; an in-flight request can finish after Stop. Rate-limit handling does not make user-account automation approved by Discord or guarantee protection from restrictions. This release has not searched or deleted real account messages during development.

Inspired by rmcord and Discrub's published functionality. Independently implemented; no Discrub source/assets were reused because its current license requires permission. [Usage, limitations and references](https://github.com/EVCORD/evencord/blob/main/src/evencordplugins/evenClean/README.md).
