# EvenCord 0.1.0-beta.6

Windows x64 now supports the reviewed Discord Stable 1.0.9266, PTB 1.0.1229 and Canary 1.0.1285 packages. The installer selects the channel and validates its build metadata, executable, exact approved archive and EvenCord loader ownership. Unsupported or altered archives remain blocked.

Channel profiles are separate. Stable keeps %APPDATA%/EvenCord. PTB uses %APPDATA%/EvenCord/channels/ptb and Canary uses %APPDATA%/EvenCord/channels/canary. Plugin enablement, settings, themes, QuickCSS, selected payload, update history and recovery records are independent. Browser storage keys also include the non-Stable host channel. No settings are automatically imported or moved. The same built-in plugin catalog is available in each channel. User-selected recording/output folders remain under user control.

Existing protocol-1 loaders and pinned keys are preserved. The legacy manifest discordChannel field remains the Stable baseline for protocol-1 boot compatibility; actual host eligibility requires both the signed archive list and the channel-to-archive catalog embedded in signed core/installer artifacts. This is not authorization for arbitrary archives or channels.

Original Discord packages were downloaded from official Discord endpoints, extracted without executing setup, and their setup and channel executables verified as signed by Discord Inc. See branding/discord-compatibility.json for provenance.

Use installer beta.5 for new PTB/Canary installations. Existing Stable users can receive this signed core update normally without changing their loader. Automatic host repatching stays disabled. Functional UI, voice and plugin testing on PTB/Canary remains with beta testers; isolated channel installation/recovery checks are development validation.
