# EvenCord 1.1.10

- Message deletion now offers all messages or a custom positive count. Removed the fixed presets, 5,000-message ceiling and 20-page search cutoff. Search continues until the chosen count or available history is exhausted, with Stop and Review available throughout.
- Deletion uses randomized spacing at or above the selected minimum. Discord cooldowns, including longer rate-limit waits, take priority before another request is sent.
- Added adapted PullUser and FakeDeafen plugins, with original credits preserved. Existing VoiceChatUtilities, HomeTyping, UnlimitedAccounts and WhosWatching remain Equicord plugins and follow their upstream updates.
- New-plugin notifications now use EvenCord branding, dismiss correctly and remember dismissal. The updater renders release notes in a readable layout.
- Integrated current Equicord changes and resolved the branded extension, Monaco editor and updater conflicts causing scheduled Action failures.
