# EvenCord 1.0.2

## Imported plugins require a fresh opt-in

This update turns off BetterMicrophone, PhilsPluginLibrary, DontControlMe, FollowUser and PasscodeLock once, while retaining their saved configuration. Re-enable only the plugins you want. The reset is recorded so future updates preserve your later choices. Reclip, Quoter Enhanced, inherited plugins and required core APIs are unaffected. BetterMicrophone enables its required library and UI APIs only when you explicitly enable it.

## Microphone interface and profiles

- Replaced the legacy account-panel injection with the existing UserAreaAPI button beside Discord's voice controls. Added an Open microphone settings button inside the plugin's own settings as a second entry point.
- Fixed empty labels in bitrate and saved-profile selectors. Profiles are available in the basic view, controls fit the modal width, and the advanced-mode switch has a clear label.
- Added a Discord default profile and corrected profile initialization, persistence and duplication. Changing a copied profile no longer renames the original saved profile.
- Native stereo remains optional and off by default. Its basic switch is unavailable until native patching is enabled. Unselected microphone controls no longer force mono or a guessed default bitrate.
- Removed the library's unrelated frame-rate and account-panel patches. Apply now reports a failure instead of silently closing on an error.

## Plugin counts

Removed the empty Userplugins card and its remote-image tooltip. Counts now update from current settings, consistently exclude hidden/system plugins, and distinguish EvenCord plugins from separately added custom plugins. The stats layout wraps to fit the available settings width.

Validation is limited to build/static checks, package identity and a focused opt-in migration check. No browser, Discord, voice or native-addon runtime testing was performed. These changes address identified source defects; further plugin-specific issues still require manual reproduction.
