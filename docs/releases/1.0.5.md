# EvenCord 1.0.5

EvenClean now opens from a trash button in the global top header alongside Discord's other header actions, including while viewing DMs or the Friends page. Enable the plugin first; it remains off by default.

The cleanup window separates This chat, Direct messages and Server channels. It reads loaded private conversations and server channels directly from Discord's stores, shows names and context, supports searchable server selection and conversation search, and lets you load more results. Selected conversations have an explicit review list and individual Remove actions. Changing the target type or server resets the selection and old preview. Selecting matching conversations handles duplicates correctly and remains capped at 100.

Optional filters are collapsed initially, progress uses readable status labels, and an overly broad label style no longer distorts switches and selectors. Access changes invalidate unavailable targets rather than silently omitting them.

Own-message checks, preview confirmation, pause/stop controls and rate-limit handling are unchanged. Only loaded, accessible conversations are available; complete history and access to closed DMs are not guaranteed. No messages were searched or deleted during development. Validation covers focused store/selection fixtures, lint, TypeScript, build and signed-package verification; the live Discord interface remains for manual testing.
