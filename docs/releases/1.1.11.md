# EvenCord 1.1.11

Message deletion now uses Discord's native menus for server, message-type and count selection, with server search. Removed clickable-label wrappers and layout clipping around those controls.

Date filters accept a date without a time. They use your local calendar, include the entire selected end date, and support a same-day range.

Search now continues until results are exhausted rather than trusting the reported total. Cursor boundaries no longer skip the next message ID. Text and media filters are applied locally. When Discord's search index is unavailable or stops advancing, the plugin can read accessible channel history instead, preserving ownership, date, access and rate-limit checks.

Message previews now have a Load more button instead of stopping at the first 100 displayed messages.
