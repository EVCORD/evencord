# EvenCord 1.1.5

Fixes the Windows update error `EPERM: operation not permitted, rename` caused by replacing an archive that Discord still has open.

Desktop updates now save a verified versioned archive and activate it on restart. The installed archive remains available if a staged download is damaged. Size and SHA-256 verification are preserved.

If your current updater shows this error, fully close Discord and run **Repair** using the [EvenCord installer](https://evcord.github.io/evencord/download/) once. Your settings and plugins are kept. Subsequent updates use the corrected updater.
