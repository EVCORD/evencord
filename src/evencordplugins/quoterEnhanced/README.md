# Quoter Enhanced

Valenced-inspired desktop quote rendering, typography (including Cairo and Tajawal), static images, stickers and animated media export. Existing media extraction, bounded fetching, decoding and GIF composition are preserved from the latest local customized source.

This replaces inherited Quoter in EvenCord through scripts/pluginSources.mjs. Settings migrate only within the existing EvenCord settings object; external Equicord data is never imported. Existing author metadata is retained. See [ATTRIBUTION.md](ATTRIBUTION.md) for upstream credits.

Provider availability, expired Discord links, GIF decoding and output animation require manual runtime validation. An EvenCord badge identifies the maintained distribution, not exclusive authorship.
