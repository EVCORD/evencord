# Quoter Enhanced attribution

Maintained in EvenCord from the user's customized Equicord Quoter source, imported on 2026-10-29. Original plugin authors remain Samwich, thororen, neoarz and prism as declared by that source. Existing copyright and GPL notices remain intact.

The layout and media work reference [Valenced Quoter](https://github.com/Accentaro/Valenced-Plugins/tree/main/plugins/quoter), whose manifest credits Benjii and whose repository includes GPL-3.0. This is a desktop adaptation, not a claim of exclusive authorship or affiliation with Valenced.

Quoter Enhanced replaces the inherited Quoter registration without deleting its upstream source. Existing Quoter settings within EvenCord migrate to the new name only if the new settings do not already exist. No external settings directory is read. Animated media behavior is preserved from the imported source and still needs manual runtime validation.
